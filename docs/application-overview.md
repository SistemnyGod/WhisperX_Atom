# Обзор приложения

## Назначение

WhisperX Atom превращает аудио совещаний в проверяемую стенограмму с временными
сегментами, спикерами и качественными метаданными. Сначала надёжно сохраняется и
получается текст, затем запускаются необязательные аналитические стадии.

## Поддерживаемые рабочие сценарии

### Файл → стенограмма

Пользователь загружает аудио или видео. Файл проходит resumable TUS-загрузку,
media processing и ASR WhisperX. Результат сохраняется как `READY` или
осмысленный `PARTIAL_READY`.

### Кнопка записи → Transcript V1/V2

Desktop проверяет готовность локального захвата и запускает current-user
AudioGraph Recorder Host. Host сохраняет выбранный микрофон в durable PCM-сегменты
и возвращает `LOCAL_READY` сразу после остановки; FFmpeg/FLAC, архив, доставка и
серверная финализация выполняются в фоне из SQLite backlog. Сеть и WhisperX не
блокируют запись. После ASR Desktop получает Transcript V1 (`ASR_DRAFT`), а
alignment/diarization могут позже создать V2; ошибка enrichment не удаляет V1.

### Голосовая команда → запись

Voice Host запускается скрыто только пока открыт Desktop и локально слушает
выбранный микрофон через Vosk. Основное wake word — «Мифодий», aliases —
«Мефодий» и временно «Атом». В managed-режиме Voice Host передаёт намерение
Desktop broker, а Desktop использует тот же `RecordingCommandService`, что и
кнопки интерфейса. До wake word аудио не сохраняется и не отправляется. Voice
Host не владеет архивом, Recorder spool или серверной обработкой.

### ИИ-помощник

Assistant работает поверх сохранённых стенограмм и evidence-механизма. Ошибки
Qwen не удаляют уже сохранённую историю. Текстовый интерфейс поддерживает
текущее совещание, историю доступных совещаний и общий чат. Голосовой маршрут
через Desktop Broker и пользовательскую API-сессию реализован, но произвольные
голосовые вопросы остаются experimental до внедрения unrestricted recognizer и
установленного voice-to-answer gate. Фактический статус описан в
[документе «Мифодий»](mifodiy-current-state.md).

## Рабочие разделы Desktop

- **Главная** — состояние системы, текущая запись, очередь и быстрые действия.
- **Запись** — preflight, выбор микрофона, старт/пауза/продолжение/завершение,
  локальный архив и доставка.
- **Совещания** — реестр, transcript workspace, speakers, summary, tasks и media.
- **Стенограммы** — поиск и просмотр доступных transcript-версий.
- **Настройки** — API-сессия, регистрация Agent, архив и LAN origin.

## Состояния результата

| Статус | Значение |
| --- | --- |
| `QUEUED` / `RUNNING` | Задание ожидает worker или выполняется |
| `READY` | Transcript прошёл обязательные проверки |
| `PARTIAL_READY` | Текст сохранён, но enrichment имеет предупреждения |
| `FAILED` | Пригодный текст получить не удалось |
| `CANCELLED` | Обработка отменена пользователем |

Доступность API, готовность локального захвата и готовность encoder — разные
состояния. При недоступном сервере Host продолжает сохранять запись локально.
