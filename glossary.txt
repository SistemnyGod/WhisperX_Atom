# Глоссарий исправлений для транскрибации.
# Формат строк:
# неверно => правильно
# Также поддерживаются: ->, →, " - ", " — "
# Для regex-правил используйте префикс re:
# re:\bскебелев\b => Скобелев

# ФИО
Скебелев Иван => Скобелев Иван
Скобель Иван => Скобелев Иван
Скабелев Иван => Скобелев Иван
Скобелив Иван => Скобелев Иван

# Медицинские термины
травм пункт => травмпункт
травмпункта => травмпункта
офталь молог => офтальмолог
рент ген => рентген
рент генография => рентгенография
нет ру до способности => нетрудоспособности
листок не трудоспособности => листок нетрудоспособности
мед заключение => медицинское заключение

# Страховые и юридические формулировки
страховой случаи => страховой случай
вреда здоровью => вред здоровью
причинение вреда здоровью => причинение вреда здоровью
несчастный случаи => несчастный случай
онлайн заявлении => онлайн-заявлении
онлайн заявка => онлайн-заявка

# Частые смысловые огрехи
по скелетам => по скелету
удаление всего => удаление стекла
с сухой лоб => со лба
погодить его => зафиксировать ее
